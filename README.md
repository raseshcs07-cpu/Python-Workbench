# Python Workbench

A beginner-friendly Python learning repo designed as a personal practice space for mastering core Python concepts through simple, runnable examples.

This repository contains short scripts and topic-based folders covering Python basics, data structures, functions, loops, conditionals, and more. It is ideal for students, self-learners, and anyone who wants a clean place to practice Python fundamentals.

## Why this repo?

- Beginner-focused explanations through code
- Small, isolated scripts for each topic
- Easy to open and run individually
- Good for learning by doing

## Topics covered

- Variables
- Data types and casting
- Strings
- Lists, Tuples, Sets, Dictionaries
- Operators
- Booleans
- Conditionals (`if`, `else`)
- Loops (`for`, `while`)
- Range
- Functions
- Scope
- Decorators
- Lambda functions
- Recursion
- Generators
- Iterators
- Modules
- Math operations
- Datetime
- JSON
- Match / pattern matching
- Arrays

## Getting started

Make sure Python is installed on your machine.

### Check Python version

```bash
python --version
```

or

```bash
python3 --version
```

## Run an example

You can run any script directly with Python:

```bash
python "get started , syntax , output/01_sys_.py"
```

```bash
python "Variables/03_variables_.py"
```

```bash
python "functions /04_functions_.py"
```

## Recommended learning order

1. `get started , syntax , output/`
2. `Variables/`
3. `Strings/`
4. `Lists/`
5. `Dictionary/`
6. `Tuples/` and `Sets/`
7. `if, else/`
8. `For,lOOp/` and `While/`
9. `functions /`
10. `Modules/`, `Math/`, `JSON/`, `Datetime/`

## Notes

This repository is a code practice workbench, not a packaged application or framework. Most files are standalone Python exercises meant to be opened and run individually.
